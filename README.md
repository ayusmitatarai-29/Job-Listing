# Job-Listing
Job Listing Website built using modern web technologies that allows users to browse job opportunities, explore companies, and view detailed job information in an easy way. The website includes multiple sections such as Home, Jobs, Companies, About, Contact and Saved Option in which you can saved your favourite job for later.
